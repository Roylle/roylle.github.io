FROM FIGMA TO FRONTEND — TECH TALK

17 slide theo trang Figma “Sửa”, gồm 07.1 và 07.2.
Nội dung, hình ảnh, màu sắc và bố cục lấy từ Figma gốc.

Mở index.html hoặc chạy một static HTTP server trong thư mục này.
Giữ nguyên thư mục assets khi sao chép trang.

Điều khiển:
← / →, Space, Page Up / Page Down: chuyển slide
Home / End: đầu / cuối
G: mục lục; F: toàn màn hình; L: con trỏ; B: tắt màn hình; ?: hướng dẫn
Điện thoại: vuốt trái / phải. Bố cục luôn giữ 16:9.
E: chỉnh chữ; thay đổi chỉ lưu ở trình duyệt đang dùng.
Xuất HTML đã sửa: đặt file tải xuống cùng thư mục assets.
